# ktx-notifier

코레일(korail.com) 승차권 검색 결과 화면을 화면 인식(pyautogui)으로 주기적으로 확인해서,
지정한 열차에 좌석이 생기면 소리 + 윈도우 알림으로만 알려주는 도구입니다.

**예매/결제는 자동화하지 않습니다.** 좌석이 생겼다는 알림을 받으면 직접 사이트에서 예매해야 합니다.
(매크로로 승차권을 자동 구매하는 행위는 철도사업법상 금지되어 있습니다.)

## 설치

```
pip install -r requirements.txt
```

## 사용 순서

1. Chrome에서 https://www.korail.com/ticket/search/general 로 이동해서
   원하는 구간/날짜로 검색 결과 화면을 띄웁니다.
   이후 프로그램이 끝날 때까지 **창 위치/크기를 바꾸지 마세요.**

2. `python calibrate_position.py` 실행 후, 마우스를 검색 결과의
   "조회하기"(새로고침) 버튼 위에 올려두고 좌표를 확인합니다.
   `Ctrl+C`로 종료하고 출력된 좌표를 `config.json`의 `search_button`에 입력합니다.

3. `python capture_region.py` 실행 후 안내에 따라
   확인하려는 열차의 좌석 상태(예: "매진" 글자)가 표시되는 영역의
   좌측 상단 → 우측 하단 순서로 마우스를 올려둡니다.
   이때 해당 열차가 실제로 "매진" 상태여야 템플릿이 정확히 캡처됩니다.
   완료되면 `templates/sold_out.png`가 생성되고 `config.json`이 자동 갱신됩니다.

4. 필요하면 `config.json`의 `check_interval_sec`(기본 20초)을 조정합니다.
   서버에 부담을 주지 않도록 너무 짧게 설정하지 마세요(15초 이상 권장).

5. `python watcher.py` 실행. "매진" 템플릿이 더 이상 해당 영역에서 발견되지 않으면
   좌석이 생긴 것으로 판단해 비프음 + 윈도우 알림을 띄웁니다. `Ctrl+C`로 종료합니다.

## 주의사항

- 화면 좌표/이미지 기반이므로 브라우저 창 위치, 배율(확대/축소), 해상도가 바뀌면
  다시 2~3번 과정을 반복해야 합니다.
- 모니터링 중에는 다른 창으로 대상 영역을 가리지 마세요.
- pyautogui의 기본 안전장치(failsafe)가 켜져 있어, 마우스를 화면 좌측 상단 모서리로
  이동하면 즉시 동작이 중단됩니다.
