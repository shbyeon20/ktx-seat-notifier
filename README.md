# ktx-notifier

코레일(korail.com) 승차권 검색 결과를 Playwright로 주기적으로 확인해서, 지정한 열차(1개
이상)에 좌석이 생기면 소리 + 윈도우 알림 + 크롬 창 앞으로 띄우기로 알려주는 도구입니다.

**예매/결제는 자동화하지 않습니다.** 좌석이 생겼다는 알림을 받으면 직접 사이트에서 예매해야 합니다.
(매크로로 승차권을 자동 구매하는 행위는 철도사업법상 금지되어 있습니다.)

화면 좌표/이미지 인식(pyautogui) 방식이 아니라, 실제 페이지 DOM을 직접 읽고 클릭하는
방식입니다. 좌표/배율/해상도에 의존하지 않아 더 안정적입니다.

## 설치

```
pip install -r requirements.txt
```

## 사용 순서

1. 기존에 켜져 있던 크롬을 전부 끕니다(같은 프로필로 디버그 포트를 열려면 필요).
   아래 명령으로 디버그 모드 크롬을 별도 프로필로 실행합니다(기존 프로필과 분리되어
   있어, 평소 쓰던 크롬을 건드리지 않습니다. 처음 실행 시 코레일에 로그인은
   필요 없지만, 필요하면 새로 로그인하면 됩니다):

   ```
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\Users\<사용자명>\ktx-chrome-profile"
   ```

2. 그 크롬 창에서 https://www.korail.com/ticket/search/general 로 이동해서
   원하는 구간/날짜로 검색하고, KTX 등 원하는 열차 종류로 필터링합니다.

3. `dom_config.json`에서 감시할 열차를 `no`(열차번호)/`dep`(출발시각) 쌍으로 지정합니다.
   `check_interval_sec`(사이클 사이 추가 대기시간, 초 단위)과
   `more_button_max_clicks`("더보기" 최대 클릭 횟수 — 감시 대상 중 가장 늦은 열차가
   화면에 나타날 때까지 필요한 횟수만큼)를 필요하면 조정합니다.

4. `python dom_watcher.py` 실행. 열려있는 디버그 크롬에서 코레일 검색 결과 탭을 찾아
   붙은 뒤, 매 사이클마다 "다음날"→"이전날" 버튼으로 목록을 새로고침하고 "더보기"를
   눌러 목록을 펼쳐서 지정한 열차들의 좌석 상태(DOM의 `sold_out` 클래스)를 확인합니다.
   좌석이 발견되면(2회 연속 확인 시) 비프음 + 윈도우 알림을 띄우고 크롬 창을 앞으로
   가져옵니다. 모든 대상 열차에 알림이 뜨면 자동 종료되며, 그 전에는 `Ctrl+C`로
   종료할 수 있습니다.

## 자동화 방식 — 왜 pyautogui 대신 CDP/DOM인가

- 이전에는 화면 인식(pyautogui)으로 좌표/이미지 템플릿을 매칭하는 방식을 썼는데,
  브라우저 창 위치/배율/해상도가 바뀌면 다시 설정해야 했고, 코레일의 대기실
  지연 때문에 새로고침이 간헐적으로 실패해 날짜가 밀리는 문제가 반복됐습니다.
- 지금은 Playwright가 **Chrome DevTools Protocol(CDP)**로 이미 열려있는 실제 크롬
  창에 직접 붙어서, 화면 픽셀이 아니라 페이지의 실제 HTML(DOM)을 읽고 클릭합니다.
  좌표/배율 의존성이 없고, 새 자동화 브라우저를 띄우는 게 아니라 평범하게 켜진
  크롬을 그대로 쓰는 방식이라 자동화 탐지 흔적(`navigator.webdriver` 등)도 남지
  않습니다.
- 조회 주기는 한 사이클(새로고침 + 더보기 펼치기)에 걸리는 시간이 자연스러운
  하한선입니다. 대기시간은 고정 sleep 대신 실제 DOM 변화(목록이 비었다가 다시
  채워지는 시점 등)를 감지해서 넘어가도록 되어 있어, 네트워크가 빠르면 그만큼
  더 빨라집니다.

## 주의사항

- `dom_watcher.py`가 붙을 대상 탭은 `--remote-debugging-port=9222`로 실행한 크롬에
  코레일 검색 결과 화면이 열려 있어야 합니다(첫 실행 시 못 찾으면 에러 메시지가 뜹니다).
- 조회만 자동화하며 예매/결제는 절대 자동화하지 않습니다.
- 폴링 속도를 과도하게 높이면 계정/IP가 일시적으로 제한될 수 있습니다(형사적
  문제라기보다는 약관 위반에 따른 서비스 제한 리스크입니다).
