# ktx-notifier

코레일(korail.com) 승차권 검색 결과 화면을 화면 인식(pyautogui)으로 주기적으로 확인해서,
지정한 열차(1개 이상)에 좌석이 생기면 소리 + 윈도우 알림 + 크롬 창 앞으로 띄우기로 알려주는 도구입니다.

**예매/결제는 자동화하지 않습니다.** 좌석이 생겼다는 알림을 받으면 직접 사이트에서 예매해야 합니다.
(매크로로 승차권을 자동 구매하는 행위는 철도사업법상 금지되어 있습니다.)

## 설치

```
pip install -r requirements.txt
```

## 사용 순서

1. Chrome에서 https://www.korail.com/ticket/search/general 로 이동해서
   원하는 구간/날짜로 검색하고, KTX 등 원하는 열차 종류로 필터링합니다.
   이후 프로그램이 끝날 때까지 **창 위치/크기를 바꾸지 마세요.**

2. `python capture_region.py` 실행:
   - 먼저 "새로고침 버튼 좌표를 설정할까요?"에 `y`를 입력하고,
     결과 화면 상단의 **"다음날"/"이전날" 화살표 버튼** 위에 순서대로 마우스를 올려 좌표를 잡습니다.
     (이 두 버튼을 번갈아 눌러 같은 날짜로 되돌아오는 방식으로 목록을 새로고침합니다.)
   - 이후 감시하고 싶은 열차마다 이름(예: `KTX207 09:04`)을 입력하고,
     해당 열차 행의 좌석 상태("매진" 표시)가 나오는 영역의 좌측 상단 → 우측 하단 순서로
     마우스를 올려 지정합니다. 이때 그 열차가 실제로 "매진" 상태여야 템플릿이 정확히 캡처됩니다
     (템플릿은 처음 한 번만 캡처하면 다른 열차에도 재사용됩니다).
   - "다른 열차도 추가할까요?"에 `y`를 입력하면 계속 추가할 수 있습니다.

3. 필요하면 `config.json`의 `check_interval_sec`(기본 20초)을 조정합니다.
   서버에 부담을 주지 않도록 너무 짧게 설정하지 마세요(15초 이상 권장).

3-1. (모니터가 여러 대인 경우) `python list_monitors.py` 실행 후 출력되는 [감지 순번]과
   위치(x, y)를 Windows 설정 > 디스플레이 화면의 모니터 배치와 비교해서, 알림이 뜨면
   크롬 창을 옮기고 싶은 모니터의 번호를 `config.json`의 `alert_monitor`에 입력합니다
   (기본값 예시는 `3`). 이 기능이 필요 없으면 `alert_monitor` 항목을 지우면 됩니다.

4. `python watcher.py` 실행. 매 주기마다 "다음날"→"이전날" 버튼을 눌러 목록을 새로고침하고,
   지정한 열차들의 좌석 상태를 확인합니다. 등록된 "매진" 템플릿이 더 이상 해당 영역에서
   발견되지 않으면 좌석이 생긴 것으로 판단해 비프음 + 윈도우 알림을 띄웁니다. 모든 대상
   열차에 알림이 뜨면 자동 종료되며, 그 전에는 `Ctrl+C`로 종료할 수 있습니다.

   `alert_monitor`가 설정되어 있으면, **마지막 남은 열차**에 좌석이 확인된 알림에서만
   크롬 창을 해당 모니터로 옮기면서 맨 앞으로 가져옵니다(그 즉시 프로그램이 종료되므로
   창이 그 모니터에 그대로 남습니다). 아직 감시할 열차가 남아있는 중간 알림에서는 창을
   옮기지 않고 제자리에서 맨 앞으로만 가져옵니다 — 서로 배율(DPI)이 다른 모니터 사이를
   오가면 창 위치가 픽셀 단위로 정확히 복원되지 않아, 옮겼다 되돌리는 방식으로는 남은
   열차의 좌표 기반 캡처/클릭이 어긋날 수 있기 때문입니다.

## 현재 설정된 감시 목록 (예시)

`config.json`은 서울→동대구, 2026-09-24 09:00~13:00 사이 KTX 18개 열차(207, 291, 103,
023, 209, 025, 211, 123, 027, 213, 029, 173, 031, 033, 215, 265, 035, 267)로 이미
계산되어 있습니다. 이 열차들이 전부 한 화면에 들어오도록 코레일 결과 화면을 **1번
모니터에서 Chrome 페이지 확대/축소 25%, 스크롤 맨 위**로 맞춰뒀습니다.

**따라서 그 크롬 창의 위치/크기/줌 배율/스크롤 위치를 바꾸면 좌표가 다 어긋납니다.**
다른 구간/날짜/열차로 바꾸고 싶으면 `capture_region.py`로 다시 잡거나, 새로 요청하세요.

## 주의사항

- 화면 좌표/이미지 기반이므로 브라우저 창 위치, 배율(확대/축소), 해상도가 바뀌면
  2번 과정을 다시 반복해야 합니다.
- 모니터링 중에는 다른 창으로 대상 영역을 가리거나 브라우저 창을 최소화하지 마세요.
  (다른 모니터에서 작업하는 것은 상관없지만, 코레일 창이 있는 모니터가 절전/잠금에
  들어가지 않도록 해주세요.)
- pyautogui의 기본 안전장치(failsafe)가 켜져 있어, 마우스를 화면 좌측 상단 모서리로
  이동하면 즉시 동작이 중단됩니다.
